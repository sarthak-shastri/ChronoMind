# ChronoMind

Team project for the ReVA Drone Video Understanding Challenge.

## Team workflow

- `main`: stable releases
- `dev`: integration branch
- `sarthak`, `shubham`, `suraj`, `rutvij`: member branches; merge changes into `dev` through pull requests

## Workstreams

Member 1 owns dataset inspection and reusable video preprocessing. Model, advanced reasoning, evaluation, and submission work are maintained by the other team members.
